Extraction Steps

  1. Move the archive to a stable folder (Downloads, Desktop, or dedicated folder)
  2. Extract in place - don't extract to temp location
  3. Verify extraction - check all files are present
  4. Keep the original archive until installation works
💡 Extract into its own folder and treat extraction as the first real step of installation

🔧 Installation Guide

Before Installing

  • Check your Mac type: Apple menu > About This Mac
  • Note: Chip (Apple Silicon) or Processor (Intel)
  • Check MacOS version
  • Close all Adobe apps

Install by File Type

.dmg Files

Double-click to mount, drag app to Applications, eject after install

.pkg Files

Runs through Installer app, needs admin password, for system-wide installs

.app Files

Move to /Applications folder, don't keep in Downloads

.zxp / CEP

Use ZXP installer, appears in Window > Extensions

.jsx / .jsxbin

Scripts run from File > Scripts, panels in Window > ScriptUI Panels

Install one plugin at a time, restart AE between installs to verify each works

🐛 Troubleshooting

Common Issues & Solutions

Issue Solution
"App is damaged" error xattr -cr /Applications/AppName.app
Plugin not showing in AE Close AE, reinstall plugin, restart
"Wrong architecture" error Check plugin matches your CPU (ARM vs Intel)
Password incorrect Type manually, check for invisible spaces
Empty folder after extract Try Keka instead of Archive Utility

Gatekeeper Fixes

# Remove quarantine from app
xattr -cr /Applications/YourApp.app

# Remove quarantine from all downloads
xattr -cr ~/Downloads

# Allow unidentified developers
spctl --master-disable

Rosetta Fixes

# Install Rosetta
softwareupdate --install-rosetta

# Check Rosetta status
/usr/sbin/softwareupdate --fetch-installer-rosetta-update

# Run Intel app with Rosetta
sudo -E rosetta /Applications/IntelApp.app/Contents/MacOS/IntelApp
